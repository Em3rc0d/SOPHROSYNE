# Quant Validation Protocol

## Benchmark ladder

Every increase in complexity must earn its place:

1. Cash / no-trade.
2. Buy and hold.
3. Simple trend rule.
4. Simple momentum rule.
5. Simple mean-reversion rule.
6. Multi-factor rule.
7. Regime-aware rule.
8. ML model.

ML is rejected as an alpha component if it fails to add robust out-of-sample value after realistic costs.

## Data controls

- point-in-time availability;
- normalized timestamps/timezones;
- no future revisions leaked backward;
- survivorship/delisting handling for equities;
- corporate actions;
- feature availability timestamps;
- immutable experiment manifest;
- source provenance.

## Validation controls

- untouched test set;
- walk-forward evaluation;
- purge/embargo where labels overlap;
- fees, spread, slippage and latency;
- turnover/liquidity constraints;
- multiple-testing log;
- Deflated Sharpe or equivalent correction;
- Probability of Backtest Overfitting where practical;
- bootstrap/Monte Carlo robustness;
- regime breakdown;
- probability calibration.

## Metrics

Do not optimize hit-rate alone. Report total/CAGR return where meaningful, volatility, Sharpe/Sortino, max drawdown, Calmar, turnover, trade count, expectancy/profit factor, tail loss, benchmark-relative return/drawdown, cost sensitivity and calibration error for probabilistic outputs.

## Probability rule

A probability can be displayed only if it is generated by an approved model and empirically calibrated. An LLM may explain it but never create it.

## Failure is a valid result

If ML does not add alpha, SOPHROSYNE can still be valuable as market translation, risk intelligence, research workflow and strategy validation.
