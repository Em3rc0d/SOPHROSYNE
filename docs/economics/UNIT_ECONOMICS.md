# Unit Economics

These are falsifiable hypotheses, not forecasts.

## Candidate pricing

- Free: limited education/translator.
- Pro: test approximately USD 12–20/month.
- Advanced/Developer: test approximately USD 30–50/month only if workflows justify it.
- B2B: separate future product/economics.

## Example thresholds

### Conservative
ARPU $12, gross margin 70%, monthly churn 10% → approximate gross-profit LTV $84 → CAC ceiling near $28 for 3× LTV/CAC.

### Base hypothesis
ARPU $19, gross margin 80%, monthly churn 6% → approximate gross-profit LTV $253 → CAC ceiling near $84 for 3×.

### Strong-retention hypothesis
ARPU $19, gross margin 82%, monthly churn 3% → approximate gross-profit LTV $519 → CAC ceiling near $173 for 3×.

Do not plan around the strong-retention case until retention is observed.

## Cost stack

Track separately:
- market/news/on-chain data licenses;
- per-user exchange entitlements;
- LLM/inference;
- storage/compute;
- payment fees;
- support;
- compliance/legal;
- security/monitoring;
- acquisition.

## Economic gates

GO if experiments indicate:
- credible paid conversion;
- gross margin target around 75%+ excluding optional pass-through entitlements;
- credible path to sub-6–7% monthly paid churn;
- acquisition economics below LTV/3.

PIVOT if users value the intelligence but retail economics fail: test B2B widget/API/partner distribution.

STOP if demand stays weak after repeated falsification or mandatory data/compliance costs structurally exceed feasible ARPU.
