# Mining Site

The mining site stores raw research, source receipts and extracted evidence before promotion into canonical product/architecture documents.

## Canonical flow

`raw source → receipt/extraction → quarry analysis → canonical decision/ADR`

Do not place unsupported summaries directly into canonical docs.

## Research domains

- `market/`
- `competitors/`
- `regulation/`
- `data-licensing/`
- `quant-science/`
- `security/`
- `user-research/`
- `economics/`

Folders should be created when the first real receipt exists; empty directory scaffolding is unnecessary.

## Receipt contract

A promoted receipt should capture, where applicable:

```yaml
receipt_id: receipt_...
title: ...
source: ...
accessed_at: ...
provenance_class: OFFICIAL | ACADEMIC | OBSERVED | INFERRED | HYPOTHESIS
claim: ...
evidence_excerpt_or_measurement: ...
confidence: high | medium | low
related_locks: []
related_quarries: []
commercial_or_legal_constraints: []
supersedes: null
superseded_by: null
```

## Promotion rules

A source is not promoted because it agrees with the thesis. It is promoted because it is relevant, traceable and survives scrutiny.

Conflicting evidence is preserved. If two credible sources disagree, canonical docs must expose the disagreement instead of averaging it away.

Time-sensitive receipts must be reviewed for staleness before they are reused to close a lock.

## Separation of concerns

- **Mining site:** evidence collection and extraction.
- **Quarries:** unresolved questions and closure criteria.
- **Canonical docs:** current project truth.
- **ADRs:** durable decisions and their consequences.
- **Experiments:** observed evidence generated by SOPHROSYNE itself.
