# Pre-Build Falsification Plan

SOPHROSYNE must earn the right to become software.

## Experiments

1. **Behavioral interviews** — 15–25 target users; observe current workflows before pitching.
2. **Chart vs Translator** — compare comprehension, time and confidence calibration.
3. **Historical Decision Records** — create true `as_of` records and review them later without rewriting history.
4. **Pricing test** — test Free / $12 / $19 / $39 positioning with qualified traffic.
5. **Retention proxy** — two-week market-state briefing; measure return behavior and evidence usage.
6. **Quant baseline** — buy-and-hold → simple rules → multifactor → regime → ML.
7. **Data-rights validation** — written provider answers for display, non-display, derived data, retention and redistribution.
8. **Legal flow review** — counsel reviews actual screens, wording and workflows.
9. **Contradiction test** — conflicting evidence must produce uncertainty or `UNKNOWN`, not invented causality.
10. **Degraded-data test** — stale or unavailable inputs must trigger degraded mode or `NO CONCLUSION`.

## Promotion rule

MK1 implementation starts only after each experiment has an owner, measurement definition, dataset/sample and explicit kill criterion.
